## Overview

Better Zoom replaces Terraria's minimal zoom control with smooth scroll-wheel zooming, a configurable minimum and maximum zoom range, separate UI scale that doesn't change with game zoom, and saved per-character zoom preferences — giving players full control over their viewing area without the harsh jump cuts of the default system.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Better Zoom** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Scroll-Wheel Zoom** | Mouse scroll wheel zooms smoothly during gameplay |
| **Custom Range** | Configure minimum and maximum zoom levels beyond vanilla limits |
| **UI Separation** | HUD UI scale stays fixed while the game world zoom changes |
| **Per-Character Prefs** | Zoom settings saved and restored per character automatically |
